🧙‍♂️ Magia

Magia é uma plataforma de aprendizado de idiomas gamificada que utiliza Inteligência Artificial para gerar atividades personalizadas e tornar o processo de estudo mais interativo, divertido e eficiente.

O projeto foi desenvolvido com foco em escalabilidade, experiência do usuário e boas práticas de desenvolvimento, utilizando uma arquitetura moderna baseada em NestJS, Angular e bancos de dados relacionais.

✨ Funcionalidades
📚 Flashcards Inteligentes

Geração automática de flashcards com auxílio de IA, adaptados ao tema e nível de conhecimento do usuário.

📝 Exercícios de Múltipla Escolha

Atividades geradas dinamicamente para reforçar vocabulário e compreensão.

✍️ Complete as Frases

Exercícios voltados para fixação de estruturas gramaticais e vocabulário.

📊 Histórico de Desempenho

Acompanhamento dos resultados obtidos em cada atividade realizada.

🏆 Sistema de Progressão

Sistema de experiência (XP) e títulos mágicos que incentivam a evolução contínua dos usuários.

🔐 Autenticação Segura

Controle de acesso baseado em JWT.

🤖 Integração com Inteligência Artificial

Geração automática de conteúdo educacional através da API da OpenAI.
